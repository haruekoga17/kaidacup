LINE共有・再公開について
index.html の og:image / og:url は、現在の一時プレビューURLを指しています。
このURLや画像は、プレビュー環境が終了すると利用できなくなる可能性があります。
将来、別の無料ホスティングへ置く場合は、そのサービスの安定したHTTPS公開URLに合わせて
index.html 内の og:image、og:image:secure_url、twitter:image、og:url を更新してください。
og-card.jpg は同じ公開フォルダに配置してください。
